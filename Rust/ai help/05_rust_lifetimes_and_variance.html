// 1. Multiple Lifetime Annotations & 'a: 'b Subtyping
// Struct holding references with independent lifetimes to prevent artificial lifetime clamping.

struct Parser<'a, 'b: 'a> {
    // 'b: 'a means lifetime 'b must outlive or match lifetime 'a
    input: &'b str,
    last_token: &'a str,
}

impl<'a, 'b> Parser<'a, 'b> {
    fn advance(&mut self) -> Option<&'b str> {
        if self.input.is_empty() {
            None
        } else {
            let (token, rest) = self.input.split_at(1);
            self.input = rest;
            self.last_token = token;
            Some(token)
        }
    }
}

fn main() {
    let source = String::from("Rust Lifetimes");
    let mut parser = Parser {
        input: &source,
        last_token: "",
    };

    if let Some(tok) = parser.advance() {
        println!("Extracted token: {}", tok);
    }
}
// 2. Higher-Rank Trait Bounds (HRTBs) with `for<'a>`
// Used when a closure or function must accept references of ANY lifetime, 
// rather than one single caller-provided lifetime.

struct BufferReader {
    data: Vec,
}

// Accepts any function that can transform a byte slice with ANY lifetime 'a into a str
fn process_buffer(reader: &BufferReader, transform: F)
where
    F: for<'a> Fn(&'a [u8]) -> &'a str,
{
    let result = transform(&reader.data);
    println!("Processed result: {}", result);
}

fn main() {
    let reader = BufferReader { data: vec![82, 117, 115, 116] }; // "Rust"
    
    process_buffer(&reader, |bytes| {
        std::str::from_utf8(bytes).unwrap_or("invalid")
    });
}
// 3. Variance & Invariance in Mutable References (&mut T is Invariant over T)
// Invariance prevents unsound code where a shorter lifetime is secretly written into a longer scope.

fn swap_refs<'a>(mut_ref: &mut &'a str, new_ref: &'a str) {
    *mut_ref = new_ref; // Safe because lifetimes match explicitly
}

fn demonstrate_invariance() {
    let static_str: &'static str = "PERMANENT";
    let mut local_holder: &'static str = static_str;

    {
        let temporary_string = String::from("short-lived");
        // &mut &'a str is INVARIANT: the compiler will REJECT attempts 
        // to pass a shorter lifetime reference if it risks lingering!
        swap_refs(&mut local_holder, "static replacement");
    }

    println!("Safely updated static ref: {}", local_holder);
}

Level 5 Architectural Pillars

Subtyping & Lifetime Bounds ('a: 'b)

Declares that lifetime 'a outlives lifetime 'b. Prevents struct fields from artificially clamping all referenced lifetimes to the shortest lifespan.

Compiler Principle: Directed Acyclic Lifetime Graph

Higher-Rank Trait Bounds (for<'a>)

Allows traits/closures to bind to a lifetime instantiated late at call-time rather than early at definition-time. Essential for async traits and parsers.

Compiler Principle: Universal Lifetime Quantification

Subtyping Variance (Covariance vs. Invariance)

Immutable references (&'a T) are Covariant over 'a (can substitute longer lifetimes). Mutable references (&mut T) are Invariant over T to prevent writing short-lived references into long scopes.

Compiler Principle: Memory Safety & Type Substitution

PhantomData<T> & Lifetime Markers

Tells the borrow checker that a struct logically owns or borrows a type or lifetime, even if it does not physically store it in a struct field.

Compiler Principle: Explicit Variance Control

Borrow Checker Variance Rulebook

Type Constructor Variance over 'a Variance over T Safety Meaning
&'a T Covariant Covariant Longer lifetimes can be passed where shorter ones are required.
&'a mut T Covariant Invariant Cannot swap underlying type T with mismatched lifetimes.
fn(T) -> U N/A Contravariant (T), Covariant (U) Arguments accept broader types; returns produce narrower types.
UnsafeCell<T> N/A Invariant Interior mutability disables automatic subtyping substitutions.
