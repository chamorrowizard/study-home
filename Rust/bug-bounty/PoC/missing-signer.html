VULNERABILITY: MISSING SIGNER CHECK

How This Exploit Works in Plain English

In Solana, every instruction lists the accounts it wants to interact with. If an on-chain program reads an account's public key (victim.pubkey()) without verifying that the account actually cryptographically signed the transaction, an attacker can pass anyone's address and impersonate them.
