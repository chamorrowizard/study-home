Async HTTP/1.1 Server from Scratch

Understand standard web infrastructure by building an HTTP engine on top of raw TCP sockets using tokio::net::TcpListener and non-blocking I/O operations.

Production Implementation

src/main.rs Tokio Async TCP 
use tokio::io::{AsyncReadExt, AsyncWriteExt};
use tokio::net::{TcpListener, TcpStream};

#[tokio::main]
async fn main() -> Result<(), Box> {
    let addr = "127.0.0.1:8080";
    let listener = TcpListener::bind(addr).await?;
    println!("[Server Engine] Listening on http://{addr}");

    loop {
        // Accept incoming TCP socket connection
        let (socket, stream_addr) = listener.accept().await?;
        println!("[TCP] Connection accepted from: {stream_addr}");

        // Spawn isolated async task per stream
        tokio::spawn(async move {
            if let Err(e) = handle_connection(socket).await {
                eprintln!("[Error] Handling socket connection: {e}");
            }
        });
    }
}

async fn handle_connection(mut stream: TcpStream) -> Result<(), Box> {
    let mut buffer = [0u8; 1024];
    let bytes_read = stream.read(&mut buffer).await?;

    if bytes_read == 0 {
        return Ok(());
    }

    let raw_request = String::from_utf8_lossy(&buffer[..bytes_read]);
    let first_line = raw_request.lines().next().unwrap_or_default();
    
    // Simple HTTP route dispatcher
    let (status_line, body) = match first_line {
        "GET / HTTP/1.1" => ("HTTP/1.1 200 OK", "{\"message\": \"Welcome to Core Rust HTTP Server\"}"),
        "GET /health HTTP/1.1" => ("HTTP/1.1 200 OK", "{\"status\": \"UP\", \"uptime_sec\": 3421}"),
        _ => ("HTTP/1.1 404 NOT FOUND", "{\"error\": \"Route not found\"}"),
    };

    let response = format!(
        "{status_line}\r\nContent-Type: application/json\r\nContent-Length: {}\r\nConnection: close\r\n\r\n{body}",
        body.len()
    );

    stream.write_all(response.as_bytes()).await?;
    stream.flush().await?;
    Ok(())
}

Architecture Breakdown

1. Non-Blocking Connection Accept Loop

listener.accept().await suspends the loop until a client initiates a TCP 3-way handshake.

2. Task-per-Connection Concurrency

tokio::spawn offloads socket reads and writes to non-blocking runtime threads without blocking the main listener loop.

3. Wire Format Construction

HTTP/1.1 mandates precise header framing ending in double CRLF (\r\n\r\n) separating headers from the payload body.

4. Zero-Copy I/O Buffers

Reading raw bytes directly into stack buffers minimizes dynamic heap allocation during request parsing.
