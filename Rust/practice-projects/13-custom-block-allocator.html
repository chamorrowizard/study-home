Custom Fixed-Size Block Arena Allocator

Take full control of memory. Implement a high-performance $O(1)$ block arena allocator using Rust's `GlobalAlloc` trait, raw pointer manipulation, and intrusive free-list tracking.

Production Implementation

src/main.rs Custom Block Arena 
use std::alloc::{GlobalAlloc, Layout};
use std::ptr::{null_mut, null};
use std::sync::Mutex;

struct Node {
    next: *mut Node,
}

pub struct FixedBlockAllocator {
    arena: [u8; BLOCK_SIZE * BLOCKS],
    free_head: Mutex<*mut Node>,
}

impl FixedBlockAllocator {
    pub const fn new() -> Self {
        assert!(BLOCK_SIZE >= std::mem::size_of::(), "Block size too small for list node");
        Self {
            arena: [0; BLOCK_SIZE * BLOCKS],
            free_head: Mutex::new(null_mut()),
        }
    }

    /// Initialize the free-list pointer chain across pre-allocated memory blocks
    pub fn init(&'static self) {
        let mut head = self.free_head.lock().unwrap();
        let start_ptr = self.arena.as_ptr() as *mut u8;

        for i in 0..BLOCKS {
            let current_block = unsafe { start_ptr.add(i * BLOCK_SIZE) as *mut Node };
            let next_block = if i + 1 < BLOCKS {
                unsafe { start_ptr.add((i + 1) * BLOCK_SIZE) as *mut Node }
            } else {
                null_mut()
            };

            unsafe {
                (*current_block).next = next_block;
            }
        }

        *head = start_ptr as *mut Node;
    }
}

unsafe impl GlobalAlloc
    for FixedBlockAllocator
{
    unsafe fn alloc(&self, layout: Layout) -> *mut u8 {
        if layout.size() > BLOCK_SIZE || layout.align() > BLOCK_SIZE {
            return null_mut(); // Requested block size or alignment exceeds arena capacities
        }

        let mut head = self.free_head.lock().unwrap();
        if head.is_null() {
            return null_mut(); // Out of memory: Arena exhausted
        }

        let current = *head;
        *head = (*current).next; // Advance free-list pointer

        current as *mut u8
    }

    unsafe fn dealloc(&self, ptr: *mut u8, _layout: Layout) {
        if ptr.is_null() {
            return;
        }

        let mut head = self.free_head.lock().unwrap();
        let new_node = ptr as *mut Node;

        // Reclaim memory block into free-list head
        (*new_node).next = *head;
        *head = new_node;
    }
}

fn main() {
    static ALLOCATOR: FixedBlockAllocator<64, 4> = FixedBlockAllocator::new();
    ALLOCATOR.init();

    unsafe {
        let layout = Layout::from_size_align(32, 8).unwrap();

        // 1. Allocate block
        let ptr1 = ALLOCATOR.alloc(layout);
        println!("Allocated Block 1 at Address: {:?}", ptr1);

        let ptr2 = ALLOCATOR.alloc(layout);
        println!("Allocated Block 2 at Address: {:?}", ptr2);

        // 2. Deallocate block
        ALLOCATOR.dealloc(ptr1, layout);
        println!("Deallocated Block 1 (Returned to Free-List)");

        // 3. Re-allocate (Reuses recycled Block 1)
        let ptr3 = ALLOCATOR.alloc(layout);
        println!("Allocated Block 3 (Reused Address): {:?}", ptr3);
    }
}

Architecture Breakdown

1. Intrusive Free-List Chaining

Unallocated memory blocks store node pointers directly inside their unallocated payload space, removing the need for separate tracking structures.

2. $O(1)$ Allocation & Deallocation

`alloc()` pops the head pointer off the free-list, and `dealloc()` pushes the freed block back onto the head pointer—both executing in deterministic $O(1)$ constant time.

3. Memory Fragmentation Immunity

Because all memory blocks are uniform fixed sizes, external fragmentation is eliminated entirely, rendering allocation performance completely predictable.

4. Hardware Pointer Alignment Validation

Validates `Layout::align()` against block boundaries during request evaluation, rejecting requests that violate CPU cache or word alignment guarantees.
