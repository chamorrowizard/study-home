Lock-Free SPSC Ring Buffer

Eliminate OS mutex lock contention. Build an ultra-low latency Single-Producer Single-Consumer (SPSC) queue utilizing hardware atomic operations and Rust memory orderings.

Production Implementation

src/spsc.rs Atomic SPSC Queue 
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::Arc;
use std::cell::UnsafeCell;

pub struct SpscRingBuffer {
    buffer: [UnsafeCell>; CAPACITY],
    head: AtomicUsize, // Read pointer owned by Consumer
    tail: AtomicUsize, // Write pointer owned by Producer
}

// UnsafeCell is not Sync by default; we explicitly assert thread safety for SPSC
unsafe impl Sync for SpscRingBuffer {}

impl SpscRingBuffer {
    pub fn new() -> Self {
        assert!(CAPACITY > 0 && (CAPACITY & (CAPACITY - 1)) == 0, "Capacity must be a power of two");
        
        // Initialize fixed array with None
        let buffer = std::array::from_fn(|_| UnsafeCell::new(None));

        Self {
            buffer,
            head: AtomicUsize::new(0),
            tail: AtomicUsize::new(0),
        }
    }

    /// Push an item into the ring buffer (Producer Thread)
    pub fn push(&self, value: T) -> Result<(), T> {
        let tail = self.tail.load(Ordering::Relaxed);
        let head = self.head.load(Ordering::Acquire);

        // Check if buffer is full
        if tail - head >= CAPACITY {
            return Err(value);
        }

        let index = tail & (CAPACITY - 1);
        unsafe {
            *self.buffer[index].get() = Some(value);
        }

        // Publish written value with Release ordering
        self.tail.store(tail + 1, Ordering::Release);
        Ok(())
    }

    /// Pop an item from the ring buffer (Consumer Thread)
    pub fn pop(&self) -> Option {
        let head = self.head.load(Ordering::Relaxed);
        let tail = self.tail.load(Ordering::Acquire);

        // Check if buffer is empty
        if head == tail {
            return None;
        }

        let index = head & (CAPACITY - 1);
        let value = unsafe { (*self.buffer[index].get()).take() };

        // Mark slot as freed with Release ordering
        self.head.store(head + 1, Ordering::Release);
        value
    }
}

fn main() {
    let queue = Arc::new(SpscRingBuffer::::new());
    let producer_queue = queue.clone();

    // Producer Thread
    let producer = std::thread::spawn(move || {
        for i in 1..=5 {
            while producer_queue.push(i).is_err() {
                std::hint::spin_loop();
            }
            println!("Producer pushed: {}", i);
        }
    });

    // Consumer Thread
    let consumer = std::thread::spawn(move || {
        let mut count = 0;
        while count < 5 {
            if let Some(val) = queue.pop() {
                println!("Consumer popped: {}", val);
                count += 1;
            } else {
                std::hint::spin_loop();
            }
        }
    });

    producer.join().unwrap();
    consumer.join().unwrap();
}

Architecture Breakdown

1. UnsafeCell & Interior Mutability

`UnsafeCell` bypasses Rust's compile-time alias checks, permitting concurrent non-overlapping reads and writes without mutex runtime overhead.

2. Acquire-Release Synchronization

`Ordering::Release` on stores and `Ordering::Acquire` on loads construct CPU memory barriers, ensuring memory writes complete before pointer updates become visible.

3. Power-of-Two Index Masking

Restricting capacity to $2^N$ allows substituting expensive CPU division modulo operations with fast bitwise AND indexing (`index & (CAPACITY - 1)`).

4. Lockless SPSC Safety

Because exactly one thread updates `tail` and exactly one thread updates `head`, race conditions are structurally impossible, avoiding CAS loops.
