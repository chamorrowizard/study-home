Lock-Free SPSC Ring Buffer Queue

Build high-performance, single-producer single-consumer queues without thread locks or mutexes. Master explicit hardware memory ordering primitives (`Acquire` and `Release`) in Rust.

Production Implementation

src/main.rs Lock-Free SPSC Queue 
use std::sync::atomic::{AtomicUsize, Ordering};
use std::sync::Arc;
use std::thread;

pub struct SpscRingBuffer {
    buffer: [Option; N],
    head: AtomicUsize, // Read pointer (Consumer)
    tail: AtomicUsize, // Write pointer (Producer)
}

impl SpscRingBuffer {
    pub const fn new() -> Self {
        assert!(N > 0 && (N & (N - 1)) == 0, "Capacity must be a power of two");
        const INIT: Option = None;
        Self {
            buffer: [INIT; N],
            head: AtomicUsize::new(0),
            tail: AtomicUsize::new(0),
        }
    }

    /// Push element into ring buffer (Producer thread)
    pub fn push(&mut self, item: T) -> Result<(), &'static str> {
        let tail = self.tail.load(Ordering::Relaxed);
        let head = self.head.load(Ordering::Acquire);

        if tail.wrapping_sub(head) >= N {
            return Err("Ring buffer full");
        }

        let index = tail & (N - 1); // Fast bitwise modulo
        self.buffer[index] = Some(item);

        // Release ordering ensures item write is visible before updating tail
        self.tail.store(tail.wrapping_add(1), Ordering::Release);
        Ok(())
    }

    /// Pop element from ring buffer (Consumer thread)
    pub fn pop(&mut self) -> Option {
        let head = self.head.load(Ordering::Relaxed);
        let tail = self.tail.load(Ordering::Acquire);

        if head == tail {
            return None; // Buffer empty
        }

        let index = head & (N - 1); // Fast bitwise modulo
        let item = self.buffer[index].take();

        // Release ordering updates head index safely for producer
        self.head.store(head.wrapping_add(1), Ordering::Release);
        item
    }
}

fn main() {
    let mut ring_buffer = SpscRingBuffer::::new();

    // Push items into lock-free queue
    ring_buffer.push(10).unwrap();
    ring_buffer.push(20).unwrap();
    ring_buffer.push(30).unwrap();

    println!("Popped: {:?}", ring_buffer.pop()); // Some(10)
    println!("Popped: {:?}", ring_buffer.pop()); // Some(20)
    println!("Popped: {:?}", ring_buffer.pop()); // Some(30)
    println!("Popped: {:?}", ring_buffer.pop()); // None
}

Architecture Breakdown

1. SPSC Guarantee (Single-Producer Single-Consumer)

Only the producer thread modifies `tail`, and only the consumer thread modifies `head`. This design eliminates hardware contention and atomic CAS loop overhead.

2. Acquire / Release Ordering Boundaries

`Ordering::Release` ensures memory writes complete before atomic index updates. `Ordering::Acquire` guarantees subsequent reads see memory changes from preceding writes.

3. Power-of-Two Bitwise Optimization

Using capacities of $2^N$ simplifies index wrapping to `idx & (capacity - 1)`, replacing expensive division instructions (`%`) with single-cycle CPU bit operations.

4. Zero Allocation Static Memory

Allocates backing storage statically using const generics (`[Option; N]`), guaranteeing zero heap allocation during queue pushes and pops.
