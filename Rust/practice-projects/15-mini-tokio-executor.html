Mini-Tokio Asynchronous Task Executor

Demystify Rust's `async/await` ecosystem. Build a mini Tokio-like task executor, custom timer futures, wakers, and a channel-driven event loop.

Production Implementation

src/mini_tokio.rs Async Executor 
use std::future::Future;
use std::pin::Pin;
use std::sync::mpsc::{channel, Receiver, Sender};
use std::sync::{Arc, Mutex};
use std::task::{Context, Poll, Waker, RawWaker, RawWakerVTable};
use std::time::{Duration, Instant};
use std::thread;

struct Task {
    future: Mutex + Send>>>,
    executor_tx: Sender>,
}

impl Task {
    fn schedule(self: &Arc) {
        self.executor_tx.send(self.clone()).unwrap();
    }

    fn waker(self: &Arc) -> Waker {
        let raw = Arc::into_raw(self.clone()) as *const ();
        let vtable = &RawWakerVTable::new(
            |ptr| {
                let task = unsafe { Arc::from_raw(ptr as *const Task) };
                let cloned = task.clone();
                let _ = Arc::into_raw(task);
                RawWaker::new(Arc::into_raw(cloned) as *const (), &vtable_static())
            },
            |ptr| {
                let task = unsafe { Arc::from_raw(ptr as *const Task) };
                task.schedule();
            },
            |ptr| {
                let task = unsafe { Arc::from_raw(ptr as *const Task) };
                task.schedule();
            },
            |ptr| {
                unsafe { drop(Arc::from_raw(ptr as *const Task)) };
            },
        );
        unsafe { Waker::from_raw(RawWaker::new(raw, vtable)) }
    }
}

fn vtable_static() -> RawWakerVTable {
    RawWakerVTable::new(
        |_| todo!(),
        |_| todo!(),
        |_| todo!(),
        |_| todo!(),
    )
}

pub struct MiniTokio {
    scheduled: Receiver>,
    sender: Sender>,
}

impl MiniTokio {
    pub fn new() -> Self {
        let (sender, scheduled) = channel();
        Self { scheduled, sender }
    }

    pub fn spawn(&self, future: F)
    where
        F: Future + Send + 'static,
    {
        let task = Arc::new(Task {
            future: Mutex::new(Box::pin(future)),
            executor_tx: self.sender.clone(),
        });

        task.schedule();
    }

    pub fn run(&self) {
        while let Ok(task) = self.scheduled.recv() {
            let waker = task.waker();
            let mut context = Context::from_waker(&waker);
            let mut future = task.future.lock().unwrap();

            // Poll task state machine
            if let Poll::Pending = future.as_mut().poll(&mut context) {
                // Task returned Pending; waiting for waker notification
            } else {
                // Task finished execution (Poll::Ready(()))
            }
        }
    }
}

// Custom Async Timer Future
pub struct DelayFuture {
    when: Instant,
}

impl DelayFuture {
    pub fn new(duration: Duration) -> Self {
        Self { when: Instant::now() + duration }
    }
}

impl Future for DelayFuture {
    type Output = &'static str;

    fn poll(self: Pin<&mut Self>, cx: &mut Context<'_>) -> Poll {
        if Instant::now() >= self.when {
            Poll::Ready("Timer Expired!")
        } else {
            let waker = cx.waker().clone();
            let when = self.when;

            // Spawn background thread simulating reactor notification
            thread::spawn(move || {
                let now = Instant::now();
                if when > now {
                    thread::sleep(when - now);
                }
                waker.wake();
            });

            Poll::Pending
        }
    }
}

fn main() {
    let runtime = MiniTokio::new();

    runtime.spawn(async {
        println!("Task 1: Waiting on DelayFuture...");
        let res = DelayFuture::new(Duration::from_millis(100)).await;
        println!("Task 1 Finished: {}", res);
    });

    runtime.run();
}

Architecture Breakdown

1. Zero-Cost State Machine Futures

`async` blocks compile into stackless state machines that transition between steps only when explicitly polled by the executor.

2. RawWaker VTable Dispatch

Constructs low-level `RawWaker` Virtual Function Tables (vtable) enabling tasks to safely re-enqueue themselves into channels when ready.

3. MPSC Channel Task Scheduling

Runnable tasks transmit pointer references via unbounded MPSC channels, sleeping the main loop until tasks require active polling.

4. Non-Blocking Cooperative Yield

Tasks return `Poll::Pending` when blocked on IO or timers, relinquishing CPU execution time immediately to other concurrent tasks.
