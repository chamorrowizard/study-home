Custom Arena Bump Allocator

Explore bare-metal memory management in Rust. Build a high-performance bump allocator using raw pointers (*mut u8), UnsafeCell, and alignment math.

Production Implementation

src/main.rs Unsafe Rust 
use std::cell::UnsafeCell;
use std::mem::{align_of, size_of};

pub struct BumpArena {
    buffer: UnsafeCell>,
    offset: UnsafeCell,
}

impl BumpArena {
    /// Create a new Arena with a fixed capacity allocation
    pub fn with_capacity(capacity: usize) -> Self {
        BumpArena {
            buffer: UnsafeCell::new(vec![0u8; capacity]),
            offset: UnsafeCell::new(0),
        }
    }

    /// Allocate a type T into the arena returning a mutable reference
    pub fn alloc(&self, val: T) -> Result<&mut T, &'static str> {
        let size = size_of::();
        let align = align_of::();

        unsafe {
            let buffer_ptr = (*self.buffer.get()).as_mut_ptr();
            let current_offset = *self.offset.get();

            // Calculate alignment padding requirement
            let current_addr = buffer_ptr.add(current_offset) as usize;
            let padding = (align - (current_addr % align)) % align;
            let aligned_offset = current_offset + padding;

            if aligned_offset + size > (*self.buffer.get()).len() {
                return Err("Arena Out Of Memory");
            }

            let dest_ptr = buffer_ptr.add(aligned_offset) as *mut T;
            
            // Write value directly to destination address
            dest_ptr.write(val);

            // Update bump offset
            *self.offset.get() = aligned_offset + size;

            Ok(&mut *dest_ptr)
        }
    }

    /// Reset arena offset for fast bulk deallocation (O(1))
    pub fn reset(&self) {
        unsafe {
            *self.offset.get() = 0;
        }
    }

    pub fn bytes_used(&self) -> usize {
        unsafe { *self.offset.get() }
    }
}

fn main() {
    let arena = BumpArena::with_capacity(1024); // 1 KB Arena Buffer

    let num = arena.alloc(42u64).unwrap();
    let text = arena.alloc("Rust Bare Metal").unwrap();

    println!("Allocated u64 value: {num}");
    println!("Allocated str value: {text}");
    println!("Total Memory Used in Arena: {} bytes", arena.bytes_used());

    // Instant reset - zero cost deallocation
    arena.reset();
    println!("Memory after reset: {} bytes", arena.bytes_used());
}

Architecture Breakdown

1. `UnsafeCell` Internal Mutability

The core building block for shared mutable state in Rust. Allows interior mutation through shared immutable references (&self).

2. Memory Alignment Boundary Math

Computes dynamic padding based on align_of::() so variable types stay properly aligned in contiguous byte memory.

3. Zero-Cost Bulk Reset (`O(1)`)

Instead of deallocating objects individually, resetting the bump offset back to `0` instantly reclaims all memory in a single CPU instruction.

4. Direct Pointer Dereferencing

Uses dest_ptr.write(val) to bypass drop semantics and copy type bytes directly to aligned target memory.
