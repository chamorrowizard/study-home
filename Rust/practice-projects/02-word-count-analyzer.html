Word Count & Text Analytics

Master high-performance text indexing using Rust's standard HashMap, entry mutability patterns, string normalization, and custom slice sorting algorithms.

Production Implementation

src/main.rs Rust Edition 2021 
use std::collections::HashMap;
use std::cmp::Reverse;

#[derive(Debug, Default)]
pub struct TextStats {
    pub total_words: usize,
    pub total_chars: usize,
    pub unique_words: usize,
    pub word_counts: HashMap,
}

impl TextStats {
    /// Constructs stats from raw input string in a single processing pass
    pub fn analyze(text: &str) -> Self {
        let mut stats = TextStats::default();
        stats.total_chars = text.chars().count();

        for raw_word in text.split_whitespace() {
            // Clean punctuation and normalize casing
            let cleaned: String = raw_word
                .chars()
                .filter(|c| c.is_alphanumeric())
                .collect::()
                .to_lowercase();

            if !cleaned.is_empty() {
                stats.total_words += 1;
                *stats.word_counts.entry(cleaned).or_insert(0) += 1;
            }
        }

        stats.unique_words = stats.word_counts.len();
        stats
    }

    /// Returns the top N most frequent words sorted in descending order
    pub fn top_words(&self, n: usize) -> Vec<(&String, &usize)> {
        let mut word_vec: Vec<(&String, &usize)> = self.word_counts.iter().collect();
        // Sort descending by count, using word lexicography as tie-breaker
        word_vec.sort_by_key(|&(word, count)| (Reverse(*count), word));
        word_vec.into_iter().take(n).collect()
    }
}

fn main() {
    let sample_text = "Rust is fast, safe, and productive. Rust enables building safe software!";
    let stats = TextStats::analyze(sample_text);

    println!("Total Words: {}", stats.total_words);
    println!("Unique Words: {}", stats.unique_words);
    println!("\nTop Word Frequencies:");

    for (word, count) in stats.top_words(5) {
        println!(" - {word}: {count}");
    }
}

Architecture Breakdown

1. Tokenizer & Normalizer

Filters out special characters and converts all letters to lowercase to guarantee accurate frequency buckets across varying input formatting.

2. HashMap Entry API

entry(key).or_insert(0) avoids double lookups by returning a mutable reference directly to the value in a single atomic key resolution.

3. Vector Sorting Pipeline

Converts key-value map references into a linear array, performing $O(N \log N)$ sorting via std::cmp::Reverse for deterministic top-ranking.

4. Encapsulated Domain Model

Uses an explicit TextStats struct with Default trait implementation to keep telemetry organized and easily unit-testable.
