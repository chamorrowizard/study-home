Thread-Safe In-Memory KV Store

Build a concurrent key-value cache system using Rust's safe concurrency primitives—Arc for thread ownership sharing and RwLock for multi-reader lock optimization.

Production Implementation

src/main.rs Rust Edition 2021 
use std::collections::HashMap;
use std::sync::{Arc, RwLock};
use std::thread;

#[derive(Clone, Default)]
pub struct KvStore {
    // Arc enables thread-shared ownership; RwLock enables multi-read / single-write
    map: Arc>>,
}

impl KvStore {
    pub fn new() -> Self {
        KvStore {
            map: Arc::new(RwLock::new(HashMap::new())),
        }
    }

    /// Set a key-value pair (requires write lock)
    pub fn set(&self, key: &str, value: &str) {
        let mut lock = self.map.write().unwrap();
        lock.insert(key.to_string(), value.to_string());
    }

    /// Read a value by key (requires read lock)
    pub fn get(&self, key: &str) -> Option {
        let lock = self.map.read().unwrap();
        lock.get(key).cloned()
    }

    /// Remove a key from the store
    pub fn delete(&self, key: &str) -> Option {
        let mut lock = self.map.write().unwrap();
        lock.remove(key)
    }

    /// Returns the current total count of items in the store
    pub fn len(&self) -> usize {
        let lock = self.map.read().unwrap();
        lock.len()
    }
}

fn main() {
    let store = KvStore::new();
    let mut handles = vec![];

    // Spawn 5 concurrent threads inserting data into shared store
    for i in 0..5 {
        let store_clone = store.clone();
        let handle = thread::spawn(move || {
            let key = format!("user_{i}");
            let val = format!("active_session_{i}");
            store_clone.set(&key, &val);
            println!("[Thread {i}] Inserted: {key} => {val}");
        });
        handles.push(handle);
    }

    // Wait for all worker threads to complete execution
    for handle in handles {
        handle.join().unwrap();
    }

    println!("\nFinal State Count: {} keys", store.len());
    println!("Retrieved user_2: {:?}", store.get("user_2"));
}

Architecture Breakdown

1. `Arc` Thread-Safe Pointer

Provides reference-counted shared ownership across OS threads without running into borrow checker lifetime conflicts.

2. `RwLock` Read-Write Lock

Enforces memory safety by granting multiple concurrent readers simultaneous access while guaranteeing exclusive write access.

3. RAII Lock Guards

Locks automatically release as soon as the handle goes out of scope, preventing resource leaks and accidental deadlocks.

4. Thread Spawning & Joining

Demonstrates OS-level concurrent execution with thread::spawn and clean thread synchronization via join() handles.
