Zero-Copy Binary Protocol & Frame Parser

Master zero-copy data processing. Learn how system-level network engines parse wire protocols directly from buffer slices without copying bytes or allocating heap objects.

Production Implementation

src/main.rs Zero-Copy Buffer Slicing 
use std::convert::TryInto;

const MAGIC_HEADER: [u8; 4] = [0x52, 0x55, 0x53, 0x54]; // "RUST"

#[derive(Debug)]
pub struct PacketFrame<'a> {
    pub opcode: u16,
    pub payload: &'a [u8], // Sliced view directly into input buffer
}

impl<'a> PacketFrame<'a> {
    /// Zero-copy parser: Reads frame from buffer slice without heap allocation
    pub fn parse(buffer: &'a [u8]) -> Result {
        if buffer.len() < 10 {
            return Err("Buffer too short for header");
        }

        // Validate Magic Header (4 bytes)
        if &buffer[0..4] != MAGIC_HEADER {
            return Err("Invalid packet magic header");
        }

        // Extract OpCode (2 bytes, Big-Endian)
        let opcode = u16::from_be_bytes(buffer[4..6].try_into().unwrap());

        // Extract Payload Length (4 bytes, Big-Endian)
        let payload_len = u32::from_be_bytes(buffer[6..10].try_into().unwrap()) as usize;

        if buffer.len() < 10 + payload_len {
            return Err("Incomplete frame payload");
        }

        // Borrow payload directly from buffer slice
        let payload = &buffer[10..10 + payload_len];

        Ok(PacketFrame { opcode, payload })
    }
}

fn main() {
    // Construct raw packet buffer in memory
    let mut raw_buffer = Vec::new();
    raw_buffer.extend_from_slice(&MAGIC_HEADER);       // Magic Header (4B)
    raw_buffer.extend_from_slice(&101u16.to_be_bytes()); // OpCode 101 (2B)
    
    let payload = b"Hello, Zero-Copy World!";
    raw_buffer.extend_from_slice(&(payload.len() as u32).to_be_bytes()); // Length (4B)
    raw_buffer.extend_from_slice(payload);                             // Payload

    // Parse packet without dynamic allocations
    match PacketFrame::parse(&raw_buffer) {
        Ok(frame) => {
            println!("OpCode: {}", frame.opcode);
            println!("Payload: {:?}", std::str::from_utf8(frame.payload).unwrap());
        }
        Err(err) => eprintln!("Parse Error: {err}"),
    }
}

Architecture Breakdown

1. Sliced Reference Views (`&'a [u8]`)

Payload data isn't copied into a new vector. The frame borrows a contiguous view from the buffer using Rust lifetimes.

2. Explicit Endian Encoding

Converts fixed-size byte ranges into integer primitive types via `from_be_bytes()`, guaranteeing cross-architecture wire compatibility.

3. Magic Byte Verification

Validates header signature bytes prior to parsing, rejecting corrupt or misaligned network streams instantly.

4. Compile-Time Safety via Borrow Checker

Rust ensures the parsed frame cannot outlive the underlying byte array, eliminating dangling reference vulnerabilities completely.
