Mark-and-Sweep Garbage Collector

Understand how dynamic runtime environments manage object lifecycles. Build a trace-based Mark-and-Sweep garbage collector capable of resolving cyclic references without memory leaks.

Production Implementation

src/main.rs Rust Mark-and-Sweep GC 
use std::collections::HashSet;

pub type GcHandle = usize;

#[derive(Debug)]
pub struct GcObject {
    pub name: String,
    pub marked: bool,
    pub references: Vec, // Pointers to other objects
}

pub struct MarkSweepGc {
    pub heap: Vec>,
    pub roots: HashSet,  // Active variables on stack
}

impl MarkSweepGc {
    pub fn new() -> Self {
        Self {
            heap: Vec::new(),
            roots: HashSet::new(),
        }
    }

    pub fn allocate(&mut self, name: &str) -> GcHandle {
        let obj = GcObject {
            name: name.to_string(),
            marked: false,
            references: Vec::new(),
        };

        // Reuse free slot if available, otherwise push
        if let Some(free_idx) = self.heap.iter().position(|slot| slot.is_none()) {
            self.heap[free_idx] = Some(obj);
            free_idx
        } else {
            self.heap.push(Some(obj));
            self.heap.len() - 1
        }
    }

    pub fn add_reference(&mut self, parent: GcHandle, child: GcHandle) {
        if let Some(Some(obj)) = self.heap.get_mut(parent) {
            obj.references.push(child);
        }
    }

    /// Mark Phase: Trace all objects reachable from Root set
    pub fn mark(&mut self) {
        let mut worklist: Vec = self.roots.iter().cloned().collect();

        while let Some(handle) = worklist.pop() {
            if let Some(Some(obj)) = self.heap.get_mut(handle) {
                if !obj.marked {
                    obj.marked = true;
                    for &child_handle in &obj.references {
                        worklist.push(child_handle);
                    }
                }
            }
        }
    }

    /// Sweep Phase: Reclaim unmarked objects and clear mark flags
    pub fn sweep(&mut self) -> usize {
        let mut freed_count = 0;

        for slot in self.heap.iter_mut() {
            if let Some(obj) = slot {
                if !obj.marked {
                    *slot = None; // Reclaim memory allocation
                    freed_count += 1;
                } else {
                    obj.marked = false; // Reset flag for next collection cycle
                }
            }
        }

        freed_count
    }

    pub fn collect_garbage(&mut self) -> usize {
        self.mark();
        self.sweep()
    }
}

fn main() {
    let mut gc = MarkSweepGc::new();

    // 1. Allocate objects
    let root_node = gc.allocate("Root Object");
    let child_node = gc.allocate("Child Object");
    let orphan_a = gc.allocate("Orphan A");
    let orphan_b = gc.allocate("Orphan B");

    // 2. Setup references (including cyclic reference between orphans)
    gc.roots.insert(root_node);
    gc.add_reference(root_node, child_node);
    gc.add_reference(orphan_a, orphan_b);
    gc.add_reference(orphan_b, orphan_a); // Cyclic orphan loop!

    println!("Objects before GC: {}", gc.heap.iter().filter(|s| s.is_some()).count());

    // 3. Trigger Garbage Collection
    let freed = gc.collect_garbage();
    println!("Garbage Collection completed. Reclaimed {freed} unreachable objects.");
    println!("Active objects after GC: {}", gc.heap.iter().filter(|s| s.is_some()).count());
}

Architecture Breakdown

1. Arena-Based Heap Handles (`GcHandle`)

Objects are stored in a contiguous `Vec>` pool and referenced via vector indices, ensuring safe memory access without `unsafe` pointers.

2. Root Set Tracing

Traces reachable nodes starting from root variables using a worklist stack. Sets the `marked` flag on every accessible node in the object graph.

3. Unreachable Sweep Phase

Sweeps through the entire heap array. Any allocation without a `marked = true` flag is reclaimed (`None`), freeing space for future allocations.

4. Cyclic Reference Resolution

Unlike reference counting (`Rc`/`Arc`), trace-based mark-and-sweep correctly frees isolated cyclic islands because they cannot be reached from the Root set.
