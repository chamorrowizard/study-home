Exploiting Untrusted Client Input

Learn how web applications fail when they blindly trust parameters computed and transmitted entirely on the client side without server-side re-validation.

Walkthrough Steps

1

Inspect the Frontend Source

Examine main.js. Notice how the calculation cost: session.cost * tickets occurs purely in the browser before dispatching an AJAX POST request.

2

Identify Client Trust Vulnerability

The server accepts JSON payloads like { cost: 5, tickets: 1000000 } without checking if the user's account balance actually supports it.

3

Execute Exploit Payload via Console

Override the ticket purchase payload in the developer console or simulation panel to bypass price checks, inflate ticket volume, and trigger the win condition.

What This Teaches

  • Never trust data sent from the client (Browser DevTools can alter any request payload).
  • Always recalculate prices, balances, and permissions securely on backend server code.
