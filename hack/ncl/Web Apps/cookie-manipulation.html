Conducting a Security Audit on the e-Gov Login Panel

Client-side access control relies heavily on values stored in browser cookies. In this challenge, web communication relies on an insecure admin=false cookie that can be manipulated to escalate privileges and access hidden administrative endpoints.

01

Open the Target Web App & Inspect Storage

Reconnaissance Phase

Open your challenge window and press F12 (or right-click and select Inspect) to launch browser developer tools. Navigate to the Application tab, expand Cookies, and submit any test entry into the login form to initialize session tokens.

// Observed Cookie State
Name: admin | Value: false
02

Modify Client-Side State via Console

Privilege Escalation

Switch to the Console tab in your developer tools. Write and execute a JavaScript command to overwrite the permission flag directly in the browser's document object.

JAVASCRIPT EXECUTION SNIPPET

document.cookie = 'admin=true';

03

Navigate to Restricted Endpoint

Access Control Bypass

Reviewing sources or clues from login.js reveals a hidden directory structure. Append /admin to your URL bar and refresh to obtain the flag.
