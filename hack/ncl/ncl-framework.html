STAGE_05 Live Execution & Rate Controls

Attempt Management Protocol

  • Track attempt counts strictly. Pause immediately after 2 failed attempts on any single flag.
  • Re-evaluate input formatting, casing, or hidden transformations prior to submitting a 3rd attempt.

Input Sanitization & Logging

  • Strip invisible spaces, carriage returns (`\r\n`), or quotation marks added by terminal selection.
  • Keep a markdown scratchpad logging every intermediate hash, payload, and command output for backtracking.
