MODULE 01 • ENCODING & DECODING

Understanding Number Bases

Our analysts obtained password dumps storing hacker passwords. All plaintext passwords appear to be encoded using different number bases. Encoding is akin to translating between languages—it reorganizes data without encrypting it.

Hexadecimal (Base 16)

Identified by prefixes like 0x using digits 0-9 and letters A-F.

Base64

Uses A-Z, a-z, 0-9, +, /, and = for padding.

Binary (Base 2)

Composed strictly of 0 and 1 grouped into 8-bit bytes.
