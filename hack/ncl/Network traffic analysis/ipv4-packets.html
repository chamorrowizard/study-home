Why Dissect Network Packets by Hand?

While automated tools like Wireshark streamline daily traffic capture, manual packet dissection provides the fundamental knowledge needed when custom protocols, scripting requirements, or legacy bugs break standard tool parsers.

01. What is a Packet?

A self-contained block of binary data transmitted over networks to power browsers, video streams, and web applications.

02. Digital Shipping

Analagous to physical packages. Headers contain transit instructions (IPs, routing, check-sums) while the payload carries actual content.

03. Pure Binary

Packets are stored and transmitted as raw bits. Strict specifications dictate how software interprets offsets into human numbers or strings.

IPv4 Header Structure (RFC 791)

Published in 1981, RFC 791 outlines the exact bit layout for IP packet headers. Each row represents 32 bits (4 bytes).

Bit 0 - 3 4 - 7 8 - 15 16 - 31
00 Version (4 bits) IHL (4 bits) Type of Service (8 bits) Total Length (16 bits)
32 Identification (16 bits) Flags Fragment Offset (13 bits)
64 TTL (8 bits) Protocol (8 bits) Header Checksum (16 bits)
96 Source IP Address (32 bits)
128 Destination IP Address (32 bits)

Header Checksum

Verifies structural integrity. Routers recalculate this at every hop; if corrupted in transit (e.g., hardware glitch or short circuit), the packet is dropped.

Time to Live (TTL)

Prevents infinite routing loops. Decremented by 1 at every router hop. When it hits 0, the packet is discarded.

Standard Manual Dissection Steps

1

Obtain Specifications

Locate official documentation (RFCs) to map bit boundaries and offsets.

2

Select Data Tools

Use manipulation utilities (e.g., CyberChef, hex/binary converters, text editors) to transform segments.

3

Locate & Extract Bit Offsets

Count binary digit offsets based on line width and isolate target fields (e.g., last 16 bits of Line 3).

4

Convert & Format Data

Transform binary into readable notations (e.g., Hexadecimal for checksums, Dotted Decimal for IPv4 addresses).
