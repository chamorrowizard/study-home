Challenge Prompt & Goal

The prompt states: "The S in HTTPS stands for secure and it uses the TLS/SSL protocol to achieve its security. Let's decrypt this traffic to find the hidden flag."

You are provided with two files: SSL Decrypt.pcapng and sslkeylog.log. This guide explains the exact protocol theory, where to click in Wireshark, and how each answer is derived.

How to Load the Decryption Key into Wireshark

By default, TLS encryption prevents you from viewing HTTP requests or contents. To make Wireshark decrypt the stream on-the-fly, feed it the pre-master secret log:

1
Open Wireshark and go to top menu: Edit > Preferences.
2
Expand Protocols on the left pane and select TLS (or SSL in older versions).
3
Locate (Pre)-Master-Secret log filename, click Browse, and select sslkeylog.log. Click OK.

1. What Cipher Suite was chosen by the secure socket server?

Where to look: Select Packet #6 (the TLS Server Hello message).

Tree Path: Packet Dissection Pane > Transport Layer Security > TLSv1.2 Record Layer: Handshake Protocol: Server Hello > Handshake Protocol: Server Hello > Cipher Suite.

Teaching Explanation & Concepts

During the TLS Handshake, the client sends a list of supported encryption algorithms (Cipher Suites) in the Client Hello packet. The server reviews that list and picks one that both parties support during the Server Hello phase. A cipher suite dictates three things: the key exchange algorithm, the bulk encryption algorithm, and the message authentication code (MAC) hash function.

2. What is the domain covered by the SSL key?

Where to look: Select Packet #6 (the TLS Server Hello message containing the certificate chain).

Tree Path: Packet Dissection Pane > Transport Layer Security > TLSv1.2 Record Layer: Handshake Protocol: Certificate > Certificates > Certificate > Signed Certificate > tbsCertificate > subject (Common Name / CN).

Teaching Explanation & Concepts

An X.509 SSL/TLS certificate proves the identity of a web server. The Subject Common Name (CN) or Subject Alternative Name (SAN) specifies the exact domain name or hostname that the certificate is authorized to protect. If a user visits a site whose domain doesn't match the certificate's CN/SAN, browsers throw a security warning.

3. What is the flag transferred over HTTPS?

Where to look: Find Packet #10 (the HTTP GET request for /flag.txt).

Action: Right-click the packet > Follow > TLS Stream (or HTTP Stream).

Teaching Explanation & Concepts

Once Wireshark successfully digests the pre-master secret key log file you loaded in the preferences, it decrypts the encrypted TLS application data layer records on the fly. Following the TCP/TLS stream stitches the request and server response together, letting you read plaintext HTTP headers and files like flag.txt.
