Executive Summary

Designed for security professionals investigating suspicious network activity using Wireshark 3.x. When reviewing packet captures (pcaps) of malware activity, post-infection traffic is frequently encrypted via HTTPS (SSL/TLS).

Key Takeaway: Decryption requires a text-based session key log file captured when the pcap was originally recorded using a Man-in-the-Middle (MitM) technique. Today's lesson uses a sample from a Dridex malware infection.

The Context Behind Encrypted Traffic

In the 1990s, web traffic relied on unencrypted HTTP. Today, almost all web browsing uses HTTPS, an encrypted communications tunnel running over TLS (or legacy SSL). While HTTPS protects user privacy, malware authors leverage the exact same tunnels to hide command-and-control (C2) communications and payload delivery.

Without Decryption

Only IP addresses, TCP ports, and visible Server Name Indication (SNI) domains are visible. Actual URLs, POST payloads, and downloaded binaries remain fully encrypted.

With Key Log File

Wireshark decrypts the TLS session on the fly, exposing full HTTP requests, parameters, server responses, and exportable malware binaries.

Encryption Key Log File & Setup

The encryption key log file (Wireshark-tutorial-KeysLogFile.txt) stores pre-master secrets. To load it into Wireshark 3.x, navigate through the preferences menu:

1 Go to Edit > Preferences
2 Expand Protocols on the left pane and select TLS
3 Browse and select your key log file under (Pre)-Master-Secret log filename

Malware Artifact Extraction & Hashing

Once decrypted, objects can be exported in Wireshark via File > Export Objects > HTTP. Linux/BSD/macOS analysts can verify and hash the extracted DLL binary:

# Verify file type

$ file extracted_binary.dll

PE32+ executable (DLL) (GUI) x86-64, for MS Windows

# Compute SHA256 Hash

$ shasum -a 256 extracted_binary.dll

31cf42b2a7c5c558f44cfc67684cc344c17d4946d3a1e0b2cecb8eb58173cb2f

Conclusion & Additional Resources

Decrypting HTTPS pcap files with session key logs is an essential skillset for incident responders analyzing modern malware campaigns like Dridex, Trickbot, Qakbot, and Ursnif.
