Message Architecture Specification

The protocol relies on a strict handshake and serialized request-response sequence between client and server.

01

Initialization

Sent by the client upon establishing connection to define transaction bounds.

N (4 Bytes): Integer defining total forthcoming hash requests.
02

Hash Request

Iterative chunks sent by client containing message integrity bytes and payload data.

Check (2B): Fixed magic value
Len (4B): Payload byte length
Data: Raw bytes to hash
03

Hash Response

Single concluding payload sent from server containing aggregated hash results.

Count (4B): Total length of response data
Hashes: Sequential fixed-length chunks

Step-by-Step Analysis Guide

Follow this breakdown to inspect network streams like a senior analyst.

1

Noise Filtering in Wireshark

Packet captures often contain background protocols like SSH (port 22) and HTTP (port 80). To isolate your custom protocol traffic cleanly, apply the standard exclusion filter:

tcp && !(tcp.port == 22) && !(tcp.port == 80)
2

TCP Stream Inspection & Hex Dump Analysis

Right-click the filtered stream and select Follow TCP Stream. Read the raw hex layout. The initial 4 bytes define request count ($N=5$), followed by the 2-byte magic check (`0x0417` = 1047 decimal).

# Calculating individual hash chunk sizes:
Total Response Advertised = 0xa0 (160 bytes)
Total Requests = 5
160 bytes / 5 requests = 32 bytes per hash chunk

Question 1 of 11 Endpoints

What is the IP address of the server?

Detailed Explanation:

Filtering traffic with tcp && !(tcp.port == 22) && !(tcp.port == 80) removes SSH and HTTP noise. The destination IP in the initial TCP handshake identifies the server hosting the custom protocol.

Question 2 of 11 Endpoints

What is the IP address of the client?

Detailed Explanation:

The client is identified by observing the source IP address that sends the initial TCP SYN packet to begin the connection.

Question 3 of 11 Endpoints

What port is the server listening on?

Detailed Explanation:

After excluding ports 22 and 80, the remaining destination port in the TCP handshake identifies the custom application’s listening port.

Question 4 of 11 Protocol Basics

What is the magic 2-byte ID in decimal representation?

Detailed Explanation:

The fixed 2-byte magic check is 0x0417. Converting it to decimal gives $(4 \times 256) + 23 = 1047$.

Question 5 of 11 Request Count

How many encrypt requests were made by the client?

Detailed Explanation:

The initialization message contains a 4-byte integer N in network byte order. It specifies the total request count; in this capture, $N = 5$.

Question 6 of 11 Request Analysis

What is the length of the first encrypt request?

Detailed Explanation:

After the first 0x0417 magic check, the 4-byte length header is 0x58, which equals 88 bytes.

Question 7 of 11 Request Analysis

What is the length of the second encrypt request?

Detailed Explanation:

The second 0x0417 magic check precedes a length header of 0x48, which converts to 72 bytes.

Question 8 of 11 Payload Calculation

How large is an individual encrypt hash in bytes?

Detailed Explanation:

The server advertises a total response size of 0xa0 (160 bytes). Dividing by the 5 requests ($160 / 5$) gives 32 bytes per hash chunk.

Question 9 of 11 Hex Responses

What was the encrypt response in hexadecimal form for the first request?

Detailed Explanation:

The server sends fixed-length hash chunks sequentially, in request order. The first request’s response therefore maps to the first 32-byte chunk in the server response payload.

Question 10 of 11 Hex Responses

What was the encrypt response in hexadecimal form for the second request?

Detailed Explanation:

Responses follow the same sequence as requests, so the second hash response maps to the second 32-byte chunk in the server response stream.

Question 11 of 11 Flag Exfiltration

What is the hidden flag being sent over the protocol?

Detailed Explanation:

The client sends text data for hashing in each request. Inspecting the request data field and Base64-decoding its payload reveals the hidden challenge flag.
