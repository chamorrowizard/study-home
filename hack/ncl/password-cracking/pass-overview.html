Linux / System Hashes HARD

> Kali Linux Shadow & Yescrypt Hashes

Analyze Linux /etc/shadow extracts using modern yescrypt ($y$), parse shadow colon delimiters, isolate target sub-fields, calculate password age, and run local system crypt hash recovery.

// When to Use This Technique

  • The challenge provides a raw dump from an /etc/shadow file containing $y$j9T$... hash strings.
  • Questions ask for explicit metadata without cracking: active account username, 22-character salt, 43-character digest, or last password change date.
  • Prompts explicitly state accounts originate from modern Kali Linux installs using default system password hashing.

// Why This Specific Approach Works

  • System Crypt Integration: Modern GPU tools like Hashcat lack direct yescrypt execution kernels. Running John the Ripper with --format=crypt routes the hash check through the host Linux operating system's native C library crypt(3) call.
  • Delimiter Isolation Mechanics: Linux shadow entries separate parameters using colons (:) and hash bounds using dollar signs ($). Understanding this structure lets you answer multiple competition questions before ever attempting a dictionary attack.

// Step-by-Step / Key Fields

// Shadow File Format:
username:$y$cost$salt$hash:lastchanged_days:min:max:warn:inact:expire
// Yescrypt ($y$) Structural Breakdown:
$y$$j9T$sZPOHCdOIBvfkKhVJRSp7.$oCNH1mJKQWFWM9HNjkjz3nFWuGPHF2RRG7j7eChfGw9
└─ ID └ cost └─── Salt (22 chars) ───┘ └─── Hash Digest (43 chars) ───────────┘
1. Locate target account & calculate change date:

Ignore entries where field 2 contains * or ! (locked accounts). Field 3 is an integer representing days elapsed since Jan 1, 1970 UTC. Multiply this number by 86,400 to convert to Unix timestamp epoch seconds or paste into a date converter.

2. Run John the Ripper via host Linux crypt(3):
john --format=crypt --wordlist=/usr/share/wordlists/rockyou.txt hashes.txt

// Tips & Gotchas

  • ! Hashcat Rejection: Hashcat does not support yescrypt. Running hashcat -m ... on yescrypt will fail. Always execute John the Ripper on a live Linux distribution (like Kali) that supports yescrypt natively.
  • ! Delimiter Stripping: The salt is bounded by $ symbols on both sides. When submitting the salt string to competition portals, do NOT include the leading or trailing $ characters.

Mask & Pattern Attacks MEDIUM

> Hashcat Mask & Custom Pattern Recovery

Execute targeted mask attacks in Hashcat (-a 3) when prompts reveal structural formatting, static prefixes, fixed suffixes, or specific character length constraints.

// When to Use This Technique

  • The prompt specifies an exact pattern clue (e.g., "Passwords are formatted as SKY-HQNT- followed by 4 digits").
  • Standard dictionary attacks fail because passwords use non-dictionary organizational prefixes or PIN numbers.
  • You identify standard 32-character hexadecimal MD5 hashes using tools like [TunnelsUP Hash Analyzer](https://www.tunnelsup.com/hash-analyzer/) or [Hashes.com Identifier](https://hashes.com/en/tools/hash_identifier).

// Why This Specific Approach Works

  • Keyspace Reduction: An unconstrained 13-character brute-force attack takes years. Specifying the static string and restricting unknown spaces to 4 digits ('SKY-HQNT-?d?d?d?d') reduces the total search space to 10,000 combinations, completing in under a second.
  • On-the-Fly GPU Generation: Mask attacks generate candidate passwords dynamically inside GPU registers, eliminating disk file I/O overhead.

// Step-by-Step / Key Fields

// Built-in Hashcat Mask Charsets:
?d = Digits (0-9)
?l = Lowercase (a-z)
?u = Uppercase (A-Z)
?s = Special Symbols (!@#$)
1. Prepare hash file:

Save target hashes to hash.txt, placing each hash on its own line with no trailing spaces.

2. Run Mask Attack (-a 3) using MD5 Hash-Mode (-m 0):
hashcat -m 0 -a 3 hash.txt 'SKY-HQNT-?d?d?d?d'

// Tips & Gotchas

  • ! Out-of-Order Output: Hashcat prints cracked outputs in the order combinations are solved, NOT input line order! Always cross-reference cracked plaintexts against target hash values before submitting answers.
  • ! Quotes Requirement: Always enclose mask patterns in single quotes ('...') in Linux terminal environments to prevent bash variable expansion from breaking the ?d directives.

Custom Scrapes & Hybrids MEDIUM

> Custom Scraping & Hybrid Attacks

Extract custom wordlists from web resources using CLI utilities (curl, grep, sed) and execute hybrid dictionary + mask combination attacks (-a 6).

// When to Use This Technique

  • Prompts hint at pop-culture themes (e.g., "Passwords are based on Pokémon names").
  • Standard wordlists like rockyou.txt fail due to niche vocabulary.
  • You need to dynamically combine wordlists with masks on the fly.

// Why This Specific Approach Works

  • Domain Vocabulary Extraction: Scraping web encyclopedias directly yields complete, up-to-date target vocabulary lists in seconds.
  • Memory-Efficient Hybrids: Hashcat Mode 6 (-a 6) dynamically pairs terms in words.txt with mask rules (?d?d) without high disk usage.

// Step-by-Step / Key Fields

1. Scrape web list & clean HTML tags to build wordlist:
curl -s -A "Mozilla/5.0" "https://bulbapedia.bulbagarden.net/wiki/List_of_Pok%C3%A9mon_by_National_Pok%C3%A9dex_number" | grep 'href="/wiki/.*(Pok' | sed 's/.*>//; s/<\/a.*//;' | sort -u > pokemon.txt
2. Execute Hybrid Attack (Wordlist + 2-digit mask suffix):
hashcat -m 0 -a 6 hash.txt svu.txt ?d?d
3. Force lowercase stream conversion:
tr 'A-Z' 'a-z' < pokemon.txt | hashcat -m 0 -a 0 hash.txt

// Tips & Gotchas

  • ! Case-Sensitive MD5 Byte Matching: Hashes operate on exact bytes. Scraped web entries are often capitalized (e.g. Pikachu). Convert to lowercase if needed via tr 'A-Z' 'a-z'.
  • ! URL Delimiters: Web scrape targets frequently contain underscores or encoding artifacts (%20). Clean outputs using sed 's/_/ /g'.
