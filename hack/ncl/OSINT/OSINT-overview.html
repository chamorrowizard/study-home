Forensics / Image EASY

EXIF Photo Metadata Analysis

Extract raw hardware, camera parameters, and spatial geolocation data directly embedded inside image headers (JPEG, TIFF, PNG).

// When to Use
When inspecting HTTPS connections, validating encryption strength, or checking issuer CAs in browser viewers.
// When to Use
Whenever given raw media files, cropped photos, or downloaded profile pictures during an investigation.
// Essential Header Fields
Timestamp: Field Create Date (round down to nearest min).
Dimensions: Field Image Size (format: 800x600).
Hardware: Fields Make (brand) & Model (camera ID).
Exposure: Field Exposure Time (e.g. 1/200).
GPS Position: Convert DMS (Degrees Minutes Seconds) to Decimal format.
$ exiftool -CreateDate -ImageSize -Make -Model -GPSPosition target.jpg
// Tips & Gotchas
Most social platforms strip EXIF data on upload; rely on raw downloaded files.
Watch time zone offsets (OffsetTimeOriginal) when calculating local creation times.

Recon / DNS EASY

DNS Record Specification & RFCs

Verify authoritative Domain Name System record types using primary IETF specification standards instead of secondary third-party summaries.

// When to Use
When auditing domain infrastructure, tracing mail servers, or verifying cryptographic domain security.
// Authoritative Record Map
DNSSEC Public Key: DNSKEY Record (Section 2 of RFC 4034).
IPv6 Address Mapping: AAAA Record (Section 2 of RFC 3596).
Zone Delegation: NS Record (RFC 1035).
Canonical Alias: CNAME Record.
$ dig +nocmd target.com ANY +multiline +noall +answer
// Tips & Gotchas
Some DNS servers block ANY; query specific types individually, such as dig target.com AAAA.
Do not confuse CNAME aliases with A or AAAA direct mappings.

Threat Intel EASY

Threat Intel & Vulnerability Research

Cross-reference software exploits, supply-chain backdoors, and legacy network specifications against National Vulnerability Databases.

// When to Use
When given server banner outputs, outdated version numbers, or named vulnerability references.
// Common Exploit Database References
POODLE Attack CVE: CVE-2014-3566 (SSLv3 CBC vulnerability).
vsftpd Backdoor: Version 2.3.4 (bind shell on port 6200 when triggered by :)).
Heartbleed Patch: OpenSSL version 1.0.1g (fixed memory leakage).
Telnet Protocol: Current RFC 854 (Original: RFC 15).
// Tips & Gotchas
Always match exact version tags; patch numbers such as 1.0.1g determine vulnerability status.
Distinguish between the protocol specification (RFC) and the software implementation (CVE).

Forensics / Web EASY

HTTP Header Field Audit

Inspect client-server communications metadata to identify original referrers, client signatures, and negotiated file types.

// When to Use
When analyzing PCAP web traffic captures, cURL responses, or browser developer logs.
// Standard Field Definitions & Typo Standard
Linked Origin: Referer (official standard misspelling with one 'r').
Client Signature: User-Agent (Browser/OS software version string).
MIME Types: Accept (Acceptable response media formats).
$ curl -I -H "Referer: https://source.site" https://target.site
// Tips & Gotchas
Competitions often test the intentional standard typo: Referer instead of Referrer.
Use curl -I to fetch headers only without downloading body content.

Recon / Domain EASY

WHOIS & Domain Delegation

Investigate domain ownership, registrar information, registration dates, and top-level domain managing organizations.

// When to Use
When mapping parent entities, tracking domain creation/expiry dates, or identifying registrars.
// Structural Breakdown & Authority
Hierarchy: Right-to-Left precedence (SLD.TLD).
Example Target: cityinthe.cloud (SLD: cityinthe | TLD: .cloud).
TLD Authority: .cloud is delegated by ICANN and managed by Aruba S.p.A.
$ whois cityinthe.cloud
// Tips & Gotchas
Privacy redaction tools may hide personal contacts; inspect Registrar and Name Server records instead.
Differentiate the domain registrar from the TLD managing entity, such as Aruba S.p.A.

Crypto / Identity EASY

PGP Keyserver Infrastructure

Query public key distribution networks to extract public key blocks, hexadecimal fingerprints, associated identity UIDs, and expiration dates.

// When to Use
When investigating target email addresses, verifying key fingerprints, or checking key validity dates.
// Data Field Identification
Fingerprint: Hexadecimal string following rsa4096/.
User Identity: Email address listed directly right of uid.
Expiration: Listed under key expir; do not confuse with cr. time.
$ gpg --keyserver keyserver.ubuntu.com --search-keys "target@email.com"
// Tips & Gotchas
If a key server is unreachable, switch to an alternative host such as keys.openpgp.org.
Separate creation date (cr. time) from expiration date (key expir).

Crypto / TLS MEDIUM

SSL/TLS Certificate Inspection

Audit x509 public key certificates to verify public key bit lengths, issuer Certificate Authority (CA) identity, and trust chain count.

// Browser Certificate Viewer Paths
Issuer Common Name: General Tab → Issued By → Common Name (CN).
Key Length (Bits): Details Tab → Certificate Fields → Subject Public Key Info.
Chain Count: Count total certificates listed in Certificate Hierarchy.
$ openssl s_client -connect target.com:443 -showcerts
// Tips & Gotchas
Distinguish the Subject, who the certificate was issued to, from the Issuer, the CA that signed it.
Bit lengths are usually powers of two, such as 2048 or 4096.

Forensics / Signal MEDIUM

1D & 2D Barcode Data Extraction

Decode visual symbology formats embedded inside intercepted graphic files (.GIF, .PNG) to uncover hidden flags and identifiers.

// When to Use
When provided graphic files containing optical bar patterns, QR codes, or product labels.
// Verification Steps
Symbology Format: Look under the output Type field (e.g. Code 128, UPC-A, EAN-13).
Extracted Payload: Read raw text value under decoded text fields.
$ zbarimg --raw barcode_target.gif
// Tips & Gotchas
Low-resolution or skewed images can cause scanner failures; crop tightly around the barcode first.
Questions may ask for the symbology type, such as Code 128, rather than only the payload.

Recon / Web HARD

OWASP & Internet Wayback Machine

Perform deep historical web footprinting using web.archive.org to recover defunct directory structures and archived reports.

// When to Use
When investigating missing web pages, defunct projects, historical meeting notes, or legacy PDF reports.
// Archive Navigation Rules
Calendar Indicators: Blue dots = successful capture | Green dots = page redirects.
URL Pattern: web.archive.org/web/[timestamp]/[target-url]
Directory Navigation: Browse archived side menus or directory indexes; search using Ctrl + F for target report titles.
// Tips & Gotchas
Green dots indicate HTTP redirects (301/302); follow the redirect to reach the final archived destination.
If a snapshot is blank, click nearby capture timestamps on the calendar timeline.
