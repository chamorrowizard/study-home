SSH / Auth Logs EASY

> SSH Brute-Force & Session Forensics

Parsing standard Linux /var/log/auth.log to identify target hostnames, attacking IP chronologies, credential brute-force targets, and successful session break-ins.

// When to Use This

  • Analyzing high-frequency Failed password for syslog events across varied ports/IPs.
  • Identifying distinct attacking IPs in precise order of initial connection attempt.
  • Tracking explicit successful log-in events (Accepted password or Accepted publickey).

// Why This Specific Approach Works

Syslog entries print field 4 as the host machine name and contain standardized strings for SSH daemon actions. Extracting client IP addresses upon initial socket establishment (Connection from) preserves true attacker chronological order regardless of whether password attempts failed or succeeded later.

// Key Commands

// Extract Hostname of SSH Server
awk '{print $4}' auth.log | sort | uniq -c
// Find Unique Attacking IPs in Chronological Order of Connection
grep -E "Connection from|Failed password" auth.log | grep -oE "([0-9]{1,3}\.){3}[0-9]{1,3}" | awk '!x[$0]++'
// Locate Target Account & Successful Compromise IP
grep "Accepted" auth.log | awk '{print "User:", $9, "IP:", $11}'
GOTCHA: Watch out for invalid users vs existing users in SSH logs. Failed password for invalid user admin shifts the IP position from column 11 to 13 compared to standard users.

Login Logs EASY

> Tab-Delimited Application Login Audit

Analyzing tabular or TSV logs to compute auth success/failure counts, isolate targeted accounts, and filter unique users via Linux pipeline tools.

// When to Use This

  • Log files separated by default tab fields containing timestamps, IP, Username, and Auth Status.
  • Quickly extracting exact line counts for specific event criteria without writing full Python scripts.

// Why This Specific Approach Works

The cut utility defaults to tab (\t) delimiters, making cut -f <N> drastically faster than regular expressions for column isolation. Combining with sort | uniq -c yields instant frequency distributions.

// Key Commands

// Extract Usernames Column (Field 3) and Count Unique Hits
cut -f 3 login.log | sort | uniq -c | sort -nr
// Count Total Failed Attempt Lines
grep -i "FAIL" login.log | wc -l
GOTCHA: Header rows in log files will contaminate wc -l outputs by 1 line. Strip headers using tail -n +2 login.log prior to processing.

VSFTPD EASY

> FTP File Transfer & Command Analysis

Parsing Very Secure FTP Daemon logs to extract file paths, file upload extension distributions, directory modifications, and user IP addresses.

// When to Use This

  • Investigating unauthorized FTP file uploads (OK UPLOAD) or directory creation (OK MKDIR).
  • Determining the most common uploaded file extensions or precise path targets.

// Why This Specific Approach Works

VSFTPD log lines enclose uploaded filenames inside quotes or separate them by commas/bytes. Setting custom field delimiters in awk -F ',' or awk -F '"' cleanly extracts full paths without complex regex.

// Key Commands

// Isolate Upload File Extensions using Comma Delimiter
grep "OK UPLOAD" vsftpd.log | awk -F ',' '{print $2}' | awk -F '.' '{print $NF}' | sort | uniq -c | sort -nr
// Locate First and Last Directory Creations for a Specific User
grep "ftpuser" vsftpd.log | grep -i "MKDIR" | head -n 1
GOTCHA: VSFTPD logs bytes transferred before the filename. Always verify field indexing with head -n 2 before passing fixed column numbers to awk.

Sysmon JSON EASY

> Windows Sysmon Process Tree Reconstruction

Reconstructing parent-child process execution trees, payload downloads, command line execution flags, and binary hashes from JSON-parsed Sysmon logs.

// When to Use This

  • Tracing process execution lineage via process_id (PID) matching against parent_process_id (PPID).
  • Identifying browser-initiated executable downloads or obfuscated CLI switches.

// Why This Specific Approach Works

Sysmon Event ID 1 logs process creation. Using jq enables declarative filtering of JSON objects by PID chains without regex failure on escaped backslashes in Windows file paths (C:\\Program Files\\...).

// Key Commands

// Filter Executable Downloads Launched via Browser Command Lines
jq '.[] | select(.process_name=="chrome.exe") | .command_line' sysmon.json
// Trace Parent Process by PID to Find Spawning Binary
jq '.[] | select(.process_id==2744) | {process_name, parent_process_id, command_line}' sysmon.json
GOTCHA: Process IDs are recycled by Windows over long sessions. Always verify that candidate parent processes have a timestamp prior to the child process start time.

Nginx Web MEDIUM

> Nginx Access Log Traffic Analysis

Parsing Nginx combined access logs to tally HTTP response codes, isolate unique IP visitors, count HTTP verb distributions, and audit User-Agent strings.

// When to Use This

  • Analyzing web application scanning activity, fuzzing attempts, or 404/500 error spikes.
  • Grouping incoming requests by HTTP Method (GET, POST, PUT) or User-Agent signatures.

// Why This Specific Approach Works

Using double quotes (") as a delimiter with cut -d '"' neatly splits web log lines into 3 main segments: pre-request metadata, the raw request line (GET /path HTTP/1.1), and post-request status/user-agent data.

// Key Commands

// Count Unique Visiting IP Addresses
cut -d ' ' -f 1 access.log | sort | uniq | wc -l
// Extract HTTP Return Code Frequency Distribution
cut -d '"' -f 3 access.log | awk '{print $1}' | sort | uniq -c | sort -nr
// Extract Unique User-Agent Strings
cut -d '"' -f 6 access.log | sort | uniq -c
GOTCHA: If URI parameters contain spaces (e.g., URL-encoded SQLi attacks), standard space-delimited awk '{print $9}' will shift field counts incorrectly. Use quote-delimited parsing (cut -d '"') instead.

Firefox SQLite MEDIUM

> Firefox Browser History Database Forensics

Querying Firefox places.sqlite / browser.sqlite databases to reconstruct visited URLs, PRTime timestamps, and search queries.

// When to Use This

  • Investigating web browser artifact files (browser.sqlite) during endpoint compromise analysis.
  • Converting Firefox microsecond PRTime timestamps into human-readable UTC dates.

// Why This Specific Approach Works

Firefox stores visits in moz_places (URLs, titles, visit counts) and moz_historyvisits. Querying SQLite CLI natively bypasses web GUI upload limitations and enables raw SQL joins.

// Key Commands

// List All Database Tables
sqlite3 browser.sqlite ".tables"
// Query Visited Sites with Human-Readable UTC Timestamps
sqlite3 browser.sqlite "SELECT url, title, datetime(last_visit_date/1000000, 'unixepoch') FROM moz_places WHERE last_visit_date IS NOT NULL;"
GOTCHA: Firefox stores timestamps in microseconds (PRTime). Dividing last_visit_date by 1000000 is strictly necessary before applying SQLite's datetime(..., 'unixepoch') function.

Squid Proxy HARD

> Squid Proxy Epoch Timestamp & Metric Analysis

Parsing Squid proxy access logs (squid_access.log) to convert Unix Epoch float timestamps, isolate client IPs, analyze response duration metrics, and isolate User-Agents.

// When to Use This

  • Logs formatted with floating-point Unix timestamps (e.g., 1598912345.123).
  • Analyzing proxy request durations (column 2, in milliseconds) or identifying target software/antivirus updates from specific client IPs.

// Why This Specific Approach Works

Standard Squid format defines: Field 1 = Epoch Time, Field 2 = Duration (ms), Field 3 = Client IP, Field 4 = Result/Status Code, Field 6 = Request Method. Using awk allows inline float-to-integer conversion and formatting.

// Key Commands

// Convert Epoch Timestamps to Human-Readable UTC Dates in Awk
awk '{print strftime("%Y-%m-%d %H:%M:%S", $1), $0}' squid_access.log | head -n 5
// Find Top 5 Longest Duration Proxy Requests (Milliseconds)
awk '{print $2, $3, $7}' squid_access.log | sort -nr | head -n 5
// Tally Unique Client IPs Serviced
awk '{print $3}' squid_access.log | sort | uniq | wc -l
GOTCHA: GNU awk's strftime() expects integer epoch seconds. Strip sub-second decimal places with int($1) on non-Linux platform builds to prevent zero-value output formatting.

SOAP XML HARD

> SOAP API XML Payload Extraction & Breach Forensics

Parsing verbose web application debug logs to isolate SOAP XML requests/responses, extract sensitive transaction records, and query payment details.

// When to Use This

  • Extracting inline XML payloads mixed with application debug text (PPAPIService: Request: ...).
  • Investigating stolen credit card, customer name, or transaction amount fields embedded in web service logs.

// Why This Specific Approach Works

Stream editing via sed -nr strips debug prefix noise and captures raw XML structures into standalone files. CLI tools like xmllint or xq enable rapid XPath querying across thousands of log records.

// Key Commands

// Extract Raw XML Request Payloads via Regex Sed
sed -nr 's/PPAPIService: Request: (.*)/\1/p' payments.log > requests.xml
// Query XML Fields directly using XPath via Xmllint
xmllint --xpath "//CardNumber/text()" requests.xml
GOTCHA: SOAP payloads often include XML declarations (<?xml version="1.0"?>) on every log line. Strip these headers during extraction to prevent malformed multi-root XML parsing errors.

Custom Binary HARD

> Custom Binary File Format Parser (.sky)

Parsing proprietary big-endian binary log files using Python struct unpacking according to formal binary header/body specification schemas.

// When to Use This

  • Parsing raw binary files starting with magic bytes 0x91534B590D0A1A0A.
  • Extracting variable-length string fields, IPv4 integers, and 32-bit big-endian Unix timestamps.

// Why This Specific Approach Works

Binary log formats use packed structures to minimize storage size. Python's struct.unpack('>I', data) enforces big-endian (>) 32-bit integer (I) decoding, enabling precise byte offset navigation.

// Key Commands

// Verify Magic Bytes in Terminal
xxd -l 8 sample.sky
// Python Binary Parser Core Template
python3 -c "import struct, socket; f=open('log.sky','rb'); magic=f.read(8); ver, ts, h_len = struct.unpack('>BI I', f.read(9)); host = f.read(h_len).decode(); print(f'Host: {host}')"
GOTCHA: Always check endianness. Mixing Big-Endian (>) with Little-Endian (<) will transform an IP like 192.168.1.1 into completely corrupted address integers.
// Log Analysis: Custom File Format [SKY Spec Walkthrough]
